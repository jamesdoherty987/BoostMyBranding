# Keyword overlay fonts (bundled)

These variable TTF files power **FFmpeg `drawtext`** for personal keyword lower-thirds. They are OFL-licensed from the [Google Fonts](https://github.com/google/fonts) repository — no system-font fallbacks.

| File | Preset id |
|------|-----------|
| `Inter-VF.ttf` | `inter` |
| `Lora-VF.ttf` | `lora` |
| `SourceSerif4-VF.ttf` | `source_serif` |
| `JetBrainsMono-VF.ttf` | `jetbrains_mono` |
| `Oswald-VF.ttf` | `oswald` |
| `DMSans-VF.ttf` | `dm_sans` |

If a file is missing, stitch fails with a clear error. Re-download from the same paths used in setup (raw `google/fonts` `ofl/*`).
